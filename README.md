# 🚀 Startup Idea Validator
AI-powered startup idea analyzer built with React + Groq AI

## What it does
Paste any startup idea and get a VC-grade analysis in seconds:
- Market size (TAM/SAM/SOM)
- Competitor analysis  
- Revenue models
- Go-to-market strategy
- Risk assessment

## Tech Stack
- React + Vite
- Groq AI (LLaMA 3)
- Deployed on Vercel
