# 🚀 Startup Idea Validator & Schemes Advisor

An AI-powered web app that provides instant VC-grade startup idea validation, real-time location & market research, personalized government scheme guidance (including Mudra Loans), and tailored marketing strategies.

---

## ✨ Key Features

- 📊 **VC-Grade Feasibility Breakdown**: Market Sizing (TAM / SAM / SOM), Problem Strength Score, Defensibility Moat, Competitor Analysis, Revenue Models, and Key Risks.
- 📍 **Location Intelligence**: Feasibility scoring (0–100), regional launch hub recommendations, demographic fit, foot traffic density, and supply chain insights.
- 🏛️ **Government Support & Mudra Loan Advisor**:
  - **Pradhan Mantri Mudra Yojana (PMMY)**: Shishu (Up to ₹50k), Kishore (₹50k–₹5L), and Tarun (₹5L–₹10L) collateral-free loan breakdown.
  - **Startup India & MSME Schemes**: Startup India Seed Fund Scheme (SISFS) grants (up to ₹20L) & capital subsidies.
  - **Interactive Checklist**: Interactive document checklist (Udyam Registration, Bank Statements, Project Reports) & step-by-step application guides.
- 📣 **Tailored Marketing Strategy**: Core campaign slogan hooks, ideal customer persona, multi-channel acquisition matrix, and viral growth hacks.
- 🖨️ **Exportable PDF Pitch Reports**: One-click print/export functionality to generate formatted pitch reports for bank loan applications and VC pitch decks.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **AI Engine**: Google Gemini AI (`gemini-2.5-flash`) / LLaMA 3.3
- **Styling**: CSS3 with modern glassmorphism UI & print media queries
- **Deployment**: Vercel

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/NalinaHM/startup-validator.git
   cd startup-validator
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   VITE_GEMINI_MODEL=gemini-2.5-flash
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```
